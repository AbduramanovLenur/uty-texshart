# Git Standards

- Keep commits focused and logically grouped.
- Do not mix unrelated refactoring with feature work.
- Do not rewrite history unless explicitly requested.
- Inspect git diff before presenting a change as complete.
- Do not commit generated files, secrets, environment files, or local tooling artifacts unless the project explicitly tracks them.
- Use the repository's existing commit convention when one exists.
- Before creating a commit, check changed files and ensure no unrelated changes are included.
