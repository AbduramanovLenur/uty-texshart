# SCSS Standards

- Prefer SCSS Modules when the project uses them.
- Follow the project's existing BEM naming convention.
- Keep styles close to the component they belong to.
- Avoid deep selectors.
- Avoid !important unless overriding a third-party component requires it.
- Prefer existing design tokens, variables, and shared mixins.
- Do not duplicate values that already exist as project tokens.
- Keep responsive behavior near the component styles.
- Avoid global styles for local component behavior.
- Do not mix unrelated component styles in one module.
