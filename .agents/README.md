# Project Agent Skills

This folder is designed to work with coding agents that support the `.agents/skills` convention, including OpenCode and Antigravity.

## Structure

```text
.agents/
├── README.md
└── skills/
    ├── antd/
    ├── api/
    ├── code-review/
    ├── debugging/
    ├── frontend/
    ├── fsd/
    ├── git/
    ├── react/
    ├── refactoring/
    ├── scss/
    ├── testing/
    └── typescript/
```

Each skill contains a `SKILL.md` with YAML frontmatter and instructions.

## Recommended project

For a React + TypeScript + FSD + Ant Design project, the most important skills are:

- frontend
- react
- typescript
- fsd
- antd
- api
- code-review
- debugging

The remaining skills provide supporting guidance for styling, testing, Git, and safe refactoring.
